# Your Travel Assistant 🌍

This project is a simple **responsive travel website** built using **HTML5** and **CSS3**. It demonstrates a clean layout, modern design principles, and responsive behavior across different screen sizes. The project was created as a **frontend practice project** focused on layout techniques and responsive web design.

## 🔹 How the website works:
- The website is divided into multiple clearly structured sections.
- Navigation links allow smooth scrolling to individual sections of the page.
- The layout automatically adapts to different screen sizes using **media queries**.
- Content layout is handled using **Flexbox** and **CSS Grid**.
- The entire website is built without JavaScript or external libraries.

## ✨ Key Features:
- **Responsive navigation bar** for desktop and mobile views.
- **Hero section** with a full-screen background image.
- **Multiple content sections**:
  - About Us
  - What We Do
  - Our Trips (image gallery)
  - Where Do You Want to Go
  - Reviews
- **Responsive image galleries** created with CSS Grid.
- **Modern layout techniques** using Flexbox.
- **No frameworks or libraries used**.

## 🛠 Technologies Used:
- **HTML5**
- **CSS3**
  - Flexbox
  - Grid
  - Media Queries

## 🎯 Purpose of the Project:
- Practice **HTML & CSS fundamentals**
- Learn **responsive web design**
- Improve layout skills using Flexbox and Grid
- Create a **portfolio-ready frontend project**
